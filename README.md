## PROJECT1_ALU
This project simulates an Arithmetic Logic Unit (ALU) using Icarus Verilog and visualizes waveforms via GTKWave.
## Operations Supported
 ADD
 SUB
 AND
 OR
 XOR
 MUL
 CMP
 NOP
## Tools Used 
 Verilog HDL 
 EDA Playground 
 EPWave
## Files
 - alu.v -> RTL Design
 - - alu_tb.v -> Testbench -
   -  waveform.png -> Simulation Waveform
   -  ## Sample Inputs
   -   A = 5 B = 4
